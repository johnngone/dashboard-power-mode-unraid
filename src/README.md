**Dashboard Power Mode**

Governor selection, a Turbo Boost checkbox, and a hardware-aware frequency ceiling in 100 MHz steps on the Unraid dashboard.

Open **Dashboard → Power Mode**. Selections apply and save automatically. Release the frequency slider to save its value.

Requires Unraid 7.0+. Other CPU managers can override these settings; Tips and Tweaks is left unchanged.
