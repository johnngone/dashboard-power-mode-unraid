**Dashboard Power Mode**

Governor selection, a Turbo Boost checkbox, and a hardware-aware frequency ceiling below the Processor display, plus sampled GHz readings beside CPU load bars.

Open **Dashboard → Processor**. Selections apply and save automatically. Release the frequency slider to save its value.

Requires Unraid 7.0+. Other CPU managers can override these settings; Tips and Tweaks is left unchanged.
